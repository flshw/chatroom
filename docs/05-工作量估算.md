# 工作量估算（v2 · 服务端/客户端分离）

## 与 v1 的差异

原方案要求「一个 HTML 同时充当服务端与客户端」，需要内嵌 Node 内核、polyglot 处理、双模式启动引导，估算 14 人日。v2 拆分后：

- 去掉单文件 polyglot / 双模式引导：−1.5 人日
- 客户端不再内嵌服务内核与 WebSocket 服务端：−1.0 人日
- 客户端不做本地 IndexedDB 持久化（每次登录全新身份）：−0.5 人日
- 增加服务端独立配置界面与 HTTP 中继端点：+0.5 人日
- 增加两端协议一致性联调：+0.5 人日

**合计约 10 人日。**

## 关键路径与风险缓冲

关键路径：阶段 3 → 4 → 6（加密协议一旦改动，两端同时受影响）。
已计入 0.5 人日缓冲用于：`Origin: null` CORS、Windows 防火墙、forge 在 Node 与浏览器下的 API 差异、sql.js wasm 路径解析。
