# 第三方库与开发环境清单

## 1. 开发环境（本机已具备，无需下载安装）

| 组件 | 检测版本 | 用途 |
|---|---|---|
| Node.js | v22.22.2 | 服务端运行时，提供 `net` / `http` / `crypto` / `fs` |
| npm | 10.9.7 | 依赖管理 |
| Python | 3.13.14 | 辅助脚本（可选） |
| npm registry | https://registry.npmjs.org/ | 依赖下载源，`npm ping` 已验证连通 |

## 2. 服务端依赖（`server/package.json`）

| 包 | 声明范围 | 实际安装 | 用途 | 许可证 |
|---|---|---|---|---|
| `ws` | ^8.18.0 | 8.23.0 | WebSocket 服务端与帧处理 | MIT |
| `node-forge` | ^1.3.0 | 1.4.3 | RSA-OAEP / AES-256-GCM / SHA-256 / PEM 编解码 | BSD-3-Clause 或 GPL-2.0 |
| `sql.js` | ^1.11.0 | 1.16.0 | SQLite WASM，内置微型数据库 | MIT |

> 三者均为纯 JavaScript 或 WASM，**无 `.node` 原生模块**，因此 Windows / Linux / macOS 无需编译即可安装运行。
> 未采用 `better-sqlite3`：需要原生编译，跨机器安装风险高。
> 未采用 `express`：原生 `node:http` 已足够，减少依赖。

## 3. 客户端内联依赖（`vendor/`，构建时打进单文件）

| 文件 | 来源 | 用途 | 体积量级 |
|---|---|---|---|
| `forge.min.js` | node-forge 1.3.0 `dist/forge.min.js` | 客户端 RSA / AES / 随机数 / 摘要 | ~260 KB |
| `protocol.js` | 本项目 `shared/protocol.js`（构建时同步到 `server/src/protocol.js`） | 协议常量（本地文件，非第三方） | ~3 KB |

> 客户端不使用任何 UI 框架、图标字体、CDN 字体或外部 CSS；
> 不引入 FingerprintJS（改为约 60 行自研指纹，减少体积与第三方指纹服务的合规顾虑）；
> 不引入 DOMPurify（消息渲染统一走 `textContent`，从源头杜绝 XSS）；
> 不引入 marked / dayjs / qrcode / Alpine（用原生实现，UI 更轻）。

## 3.1 管理页面本地依赖（v3 新增）

| 文件 | 来源 | 用途 | 说明 |
|---|---|---|---|
| `server/admin/assets/forge.min.js` | 同上 `vendor/forge.min.js` 的副本（288 KB） | 管理页「RSA 私钥登录」时对挑战码做 RSA-PSS 签名 | 局域网 `http://<IP>/admin` 不是安全上下文，`crypto.subtle` 不可用，故必须本地化一份纯 JS forge。私钥只在浏览器内用于签名，不上传。 |

`client/dist/chatroom.html`（v5.1：**415.9 KB**）内联 6 段脚本：协议、forge、加密核心、身份文件、网络层、应用逻辑。构建后零外部资源引用、无未替换占位符，可离线双击运行。

## 3.2 v4 说明：未引入任何新的第三方运行时依赖

v4 新增的门户页 `server/public/welcome.html`、机器人系统 `server/src/bots.js`、路径模块 `server/src/paths.js`、指标端点 `/api/metrics`、基准脚本与全部移动端样式，均为**本项目自研代码或原生 Node / 浏览器 API**：

| 能力 | 使用的原生 API |
|---|---|
| `/api/metrics` | `process.memoryUsage()` / `process.cpuUsage()` / `process.pid` / `os` |
| `/api/client-info` | `node:crypto` 的 `createHash('sha256')` + `os.networkInterfaces()` |
| 机器人定时轮换 | `setInterval` / `Math.random()`，发言复用现有 `node-forge` AES-GCM |

## 3.3 v5 说明：同样未引入任何新的第三方运行时依赖

v5 的身份链写入过滤、配置注释、版权管理、只看在线、登录页身份选项外置、随机时间戳、在线改名、大厅直聊、公私聊快切与全部 UI 美化，**均为自研代码或原生浏览器 / Node API**，依赖清单与 v4 完全一致：

| 能力 | 使用的原生 API / 现有依赖 |
|---|---|
| 大厅直聊 E2EE | 现有 `node-forge` RSA-OAEP + AES-256-GCM；一次性密钥用 `ChatCrypto.randomBytes()`，接收方公钥封装用 `wrapKeyFor()` |
| 直聊 AAD 隔离 | 字符串拼接 `['dm', room, uid, seq, ts].join('|')`，无新库 |
| 临时用户随机时间戳 | `Date.now().toString(36)` + `randomBytes(2)`，无新库 |
| UI 美化 | 原生 CSS 渐变 / `backdrop-filter` / `mask-image` / 媒体查询，无 UI 框架 |
| 版权头批量写入 | `node:fs` / `node:path`，无新库 |
| 配置注释与广播 | 现有 `/api/config` 与 WebSocket 信封，无新库 |
| 身份库 Vault | `localStorage` + 现有 PBKDF2/AES-GCM 加密实现 |
| 多房间 / 拖拽 / 移动适配 | 原生 DOM、`dataTransfer.files`、`100dvh`、`env(safe-area-inset-*)` |
| 隔离压测路径 | `process.env.CHATROOM_DATA_DIR` / `CHATROOM_LOG_DIR` |

因此**服务端依赖仍是 `ws` / `node-forge` / `sql.js` 三个纯 JS+WASM 包**，客户端内联依赖仍只有 `forge.min.js` + 自研 `protocol.js`，跨平台免编译结论（ADR-009）不变。

## 5. 备选库（未启用，仅记录选型过程）

| 库 | 用途 | 未启用原因 |
|---|---|---|
| `libsodium-wrappers-sumo` 0.7.15 | X25519 密封盒 / 前向保密 | WASM 内联后客户端体积约翻倍，本版优先轻量 |
| `sql.js` 替代品 `lowdb` | JSON 存储 | 非真 SQL，不满足「微型数据库」语义 |
| `@fingerprintjs/fingerprintjs` 3.4.2 | 浏览器 ID | 自研指纹足够，避免第三方依赖 |
| `Dexie` 4.0.11 | IndexedDB 封装 | 客户端无需本地持久化（每次登录全新身份） |
| `Alpine.js` 3.14 / `marked` / `dayjs` / `qrcode-generator` | UI 与格式化 | 原生实现即可，保持客户端简洁 |
| `esbuild` / `terser` | 打包压缩 | 本项目自研 30 行内联脚本即可，避免额外工具链 |

## 6. 依赖本地化原则

- 所有第三方库文件实际下载到 `vendor/` 与 `server/node_modules/`，**运行时不发起任何公网请求**。
- 交付客户端是单个 HTML 文件，内含全部依赖，可离线双击运行。
- 服务端 `node_modules` 随目录分发；若目标机器无网络，可直接拷贝整个 `server/` 目录。
