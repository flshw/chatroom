## 3. 服务端（`server/`）

| 文件 | 用途 |
|---|---|
| `package.json` / `package-lock.json` | 依赖声明与锁定：`ws` 8.23.0、`node-forge` 1.4.3、`sql.js` 1.16.0（全为纯 JS/WASM，无原生编译） |
| `src/main.js` | 入口：加载配置/密钥/数据库，装配 `BotManager`，创建 Hub 与 HTTP+WS 服务，打印内网 IP、端口与 `/welcome`，软重启与优雅退出落盘 |
| `src/protocol.js` | 协议常量自包含副本（由构建脚本从 `shared/protocol.js` 同步）；v4 增加 `MAX_ACTIVE_ROOMS=3`、`E_ROOM_LIMIT`、`IDENTITY_VAULT_KEY` |
| `src/paths.js` | **v4** 统一路径：`CHATROOM_DATA_DIR` / `CHATROOM_LOG_DIR` / `FILES_DIR`，支持隔离压测与多实例部署 |
| `src/bots.js` | **v4** 机器人池（1000 持久身份）、10～20 在线轮换、自动回复、ambient 闲聊、配置持久化与管理 API 支撑 |
| `src/config.js` | 配置读写（`data/config.json`），支持 `--port` 与 `CHATROOM_PORT` 覆盖 |
| `src/crypto.js` | RSA 密钥对生成/加载、OAEP 封装、AES-256-GCM、RSA-PSS 签名验签、混合加密、归档主密钥封装 |
| `src/database.js` | sql.js 微型数据库：建表、密文归档写入、历史查询、防抖导出到 `chat.db`；**v4** 身份表增加 `permanent` / `is_bot` 字段与迁移、机器人身份查询 |
| `src/session.js` | `Session` 抽象 + `WsSession` / `RelaySession`；**v4** 增加 `BotSession`（机器人不消费服务端推送） |
| `src/hub.js` | 认证、持久身份恢复、权限检查、房间与私聊 E2EE、会话密钥封装交付、密文路由、加密归档、管理态统计、房间删除；**v4** 增加消息 hook、机器人挂载/卸载、成员 bot 标记、最多同时 3 个房间限制 |
| `src/http.js` | 静态托管、全部 `/api/admin/*` 与 `/api/file/*` 与 `/api/invite/*`、管理员 token 鉴权、`POST /relay`、WebSocket 升级、心跳；**v4** 增加 `/welcome`、`/download/chatroom.html`、`/api/metrics`、`/api/client-info`、`/api/admin/bots*` |

| `src/identity.js` | **v3** 持久身份注册/恢复证明校验、封禁/禁言/房间授权、身份变更写链 |
| `src/admin.js` | **v3** 管理员 RSA 密钥对、PBKDF2 口令、挑战签名登录、token 发行与校验 |
| `src/invite.js` | **v3** `CR1.` 完整邀请码生成/解析/HMAC 防伪 |
| `src/files.js` | **v3** png/pdf/zip 白名单、密文文件落盘与房间级联删除 |

| `public/welcome.html` | **v4** 客户端下载页与使用说明：在线聊天/下载双入口、SHA-256 与公钥指纹、身份 XML 步骤、FAQ |

## 8. 归档原则

- 设计阶段产出的思维导图、框架图、库清单、估算**全部保留**，并明确标注 v1 → v2 的修订点，不覆盖删除。
- 编码阶段发现的实现偏差（注册混合加密、forge 验签 API）以 ADR-008 形式补记，并同步修订对应设计文档。
- 运行时生成的密钥与数据库不纳入版本管理（见 `.gitignore`），但保留在工作区供直接使用。
