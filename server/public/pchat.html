Private Chatroom 私密聊天室

为个人用户设计的一次性私密聊天室：申请时设定名称、生命期与人数上限，拿到一份专属单文件客户端发给朋友，对方只填昵称即可进入，无需注册账号。

  • 房间双层加密：TLS 只保传输，消息在应用层再以逐成员公钥封装，服务端零解密能力
  • 生命期：默认 24 小时、最长 72 小时，到期自动销毁密文与密钥
  • 免注册入房：朋友双击 HTML、输入昵称即可加入，支持文字 / 语音 / 视频 / 文件
  • 独立仓库：gitee.com/klmycjs/private-chatroom
