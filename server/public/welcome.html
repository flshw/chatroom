快速开始

同一局域网内的手机、电脑都可以直接访问上面的地址。

  1. 拿到地址：把上方显示的 http://IP:端口/ 发给同事，或在浏览器地址栏直接输入。
  2. 填写登录信息：用户名任意，服务器 IP 与端口通常会自动带出；有邀请码时粘贴 CR1.…，会自动填地址并直达房间。
  3. 核对指纹：首次连接请对照本页右上角的服务器公钥指纹，防止连到伪造服务器。
  4. 开始聊天：默认进入大厅，可创建房间、复制邀请码、点击成员发起端到端加密私聊、拖拽发送 png/pdf/zip 文件。
若其它机器无法访问，请在服务器放行端口：Windows 用 netsh advfirewall firewall add rule name="ChatRoom" dir=in action=allow protocol=TCP localport=8080；Linux 用 sudo ufw allow 8080/tcp。双击本地 HTML 若被混合内容策略拦截，请改用上面的在线地址。

身份文件（XML）· 保存 / 导入 / 切换

默认每次登录都是全新身份；想复用同一昵称与 UID，请使用身份文件。

保存身份
登录页展开「身份文件」→ 勾选「保存身份文件」→ 连接成功后自动下载 XML。强烈建议设置本地加密口令。
导入身份
登录页选择 .xml 文件（加密文件填口令）→ 连接时以 RSA-PSS 挑战签名恢复同一 UID。私钥永不上传。
身份库与快速切换
聊天界面右上角「切换身份」可保存多份身份、重命名、导出、删除，点一下即断开并以该身份重连。
跨设备迁移
用「导出 XML」把身份文件传到另一台设备再导入。浏览器本地存储不跨设备同步，XML 是唯一可移植载体。
服务端只保存用户公钥与身份哈希链；私钥只存在于你的 XML 文件或浏览器身份库中，管理员也无法冒充你登录。

功能一览

多房间同时在线
大厅 + 两个房间可同时保持连接，标签切换，未读消息有角标提示。
端到端加密私聊
会话密钥由客户端生成并用双方公钥封装，服务端不持有密钥、无法解密内容。
邀请码直达房间
CR1. 开头的邀请码含 IP、端口、邀请人与房间信息，粘贴后自动填地址并进房。
加密附件与预览
仅 png / pdf / zip，≤8 MB；内容端到端加密后由服务器转发，png 与 pdf 可在线预览。
机器人陪聊
服务器内置机器人池，自动维持若干在线并回复消息，数量可在管理台调整。
移动端适配
手机浏览器直接使用，侧栏抽屉化、房间标签横向滚动、输入框防缩放。

常见问题

连接一直失败 / 提示检查防火墙

确认服务端已启动、IP 与端口正确、服务器防火墙放行该 TCP 端口；两台机器必须能互相 ping 通。若走代理，在登录页「高级设置」填 http://代理地址/relay。

为什么不用 HTTPS？安全吗？

局域网自签证书无法被其它设备信任。本项目不依赖浏览器原生 crypto.subtle，改用内联的纯 JS 加密库，在普通 http 页面同样可用；注册用服务器公钥加密、聊天用 AES-256-GCM、密钥用各自公钥单独封装。风险在于「首次连接信任」，所以请核对本页指纹。

历史消息能被别人看到吗？

普通房间的归档由服务器归档密钥加密落盘，仅服务端管理员可查看；端到端加密私聊服务端只存密文，管理员也只能看到元数据。代理中继全程只见密文。

身份文件丢了怎么办？

无法找回（服务端没有你的私钥）。重新用新身份登录即可；若之前在身份库中保存过，可从身份库导出备份。建议给重要身份设置口令并离线备份 XML。
