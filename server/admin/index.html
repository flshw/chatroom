系统维护

以下操作会修改服务端持久数据，请谨慎使用；重置操作不可恢复。

用户管理

禁止登录后该身份无法重新登录；禁止发言后仍可接收消息；房间权限为空表示不限制。默认显示全部身份记录，可切换为只查看当前在线用户。

房间管理

删除房间会同时清除该房间的归档消息与文件；E2EE 私聊仅显示元数据。改名会立即广播给所有在线客户端，房间标签同步刷新。
