快速开始

  1. 拿到地址：把显示的 http(s)://IP:端口/ 发给同事，或直接在浏览器输入。
  2. 填写登录信息：用户名任意，服务器地址通常自动带出；有邀请码时粘贴 CR1.… 会自动填地址并直达房间。
  3. 核对指纹：首次连接请对照上方「服务器公钥指纹」，防止连到伪造服务器。
  4. 开始聊天：默认进入大厅，可创建房间、复制邀请码、点成员发起加密私聊、拖拽发送文件，房间内点「视频」可发起端到端加密视频通话。

功能一览

多房间同时在线
大厅 + 两个房间可同时保持连接，标签切换，未读有角标。
端到端加密私聊
会话密钥由客户端生成并用双方公钥封装，服务端不持有密钥。
邀请码直达房间
CR1. 邀请码含地址与房间信息，粘贴即进房。
加密附件 / 语音 / 视频
附件与语音端到端加密转发；房间内视频为 P2P 端到端加密。
身份文件（XML）
保存 / 导入 / 切换身份，私钥永不上传，可跨设备迁移。
移动端适配
手机浏览器直接使用，侧栏抽屉化、输入框防缩放。

常见问题

连接失败 / 提示检查防火墙

确认服务端已启动、IP 与端口正确、服务器防火墙放行该 TCP 端口；两台机器需能互相 ping 通。走代理时在「高级设置」填 http://代理地址/relay。

为什么不用 HTTPS 也安全？

本项目不依赖浏览器原生 crypto.subtle，改用内联纯 JS 加密库，普通页面同样可用；注册用服务器公钥加密、聊天用 AES-256-GCM、密钥用各自公钥单独封装。风险在「首次连接信任」，请核对上方指纹。

历史消息能被别人看到吗？

普通房间归档由服务器加密落盘，仅管理员可查看；端到端加密私聊服务端只存密文。代理中继全程只见密文。

身份文件丢了怎么办？

无法找回（服务端没有你的私钥）。重新用新身份登录即可；若之前在身份库保存过，可从身份库导出备份。
